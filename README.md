# Nexus · Etapa 1 — Apresentação

Site Next.js da apresentação **Comunicação Interna e Feedback** para a Nexus Serviços & Logística.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

### Controles

- `←` `→` ou botões: navegar slides
- `Espaço`: próximo
- `F`: tela cheia
- Swipe no celular

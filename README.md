# Nexus · Etapa 1 — Apresentação (estilo Netflix)

Site Next.js da apresentação **Comunicação Interna e Feedback** para a Nexus Serviços & Logística — experiência cinematográfica inspirada na Netflix (perfis, splash, home com rows, player de episódios).

## Rodar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

### Fluxo

1. **Quem está assistindo?** — escolha o perfil
2. **Splash NEXUS** — intro cinematográfica
3. **Home** — billboard + fileiras (Top 5, Continue assistindo, etc.)
4. **Player** — slides como episódios da temporada

### Controles do player

- `←` `→` ou botões: navegar episódios
- `Espaço`: próximo
- `E`: abrir lista de episódios
- `M`: mute (visual)
- `F`: tela cheia
- `Esc`: fechar painel / sair do player
- Swipe no celular
